# Parameter generation

`generate_neuron_params.py` converts constants from the original research
team's `C_fixedpoint/Single_Neuron/neuron_fixed.c` and
`C_fixedpoint/1D_Synfire/Synfire_1D_3neur_fixed.c` into the fixed-point
integer values used by RTL.

## Source and attribution

The parameter values, fractional-bit formats, truncation behaviour, and
floating-to-fixed conversion method are reproduced from the supplied reference
implementation for:

> S. Bhattacharyya, P. R. Ayyappan and J. O. Hasler, "Towards Scalable Digital
> Modeling of Networks of Biorealistic Silicon Neurons," IEEE JETCAS, 2023.
> DOI: `10.1109/JETCAS.2023.3330069`

The Python file automates their existing conversion method so the generated
SystemVerilog constants are repeatable. It does not introduce a new fixed-point
conversion method.

Run it from the repository root:

```powershell
python scripts/generate_neuron_params.py
```

It writes:

```text
hdl/packages/neuron_params_generated_pkg.sv
```

The conversion matches the C expression:

```c
(int)(value * (1 << fractional_bits))
```

The formats copied from the reference C model are:

| Values | Fractional bits |
|---|---:|
| Initial neuron states | 24 |
| Model constants and timestep | 24 |
| Matrix coefficients | 23 |
| Input current | 8 |
| Triangle state and slope | 16 |
| Triangle spike threshold and synapse coefficients | 24 |
| Synapse pulse output and excitatory scale | 8 |

`VNA_OFFSET_Q24` stays in `neuron_params_pkg.sv`, alongside `ONE_Q24` and
`ONE_Q8`, because these shared neuron arithmetic constants are already used by
the existing single-neuron RTL. The generated package contains the source
model and network configuration values generated by this script.

For values stored in C `float` variables or arrays, the script first rounds to
32-bit `float` and then truncates toward zero. It converts direct C expressions
at double precision, and copies fixed integer literals without reconversion.

The package includes the triangle generator's initial value, upper bound,
spike threshold, and two slope pairs. It also includes the synapse triangle
scaling, channel offsets, coupling, exponent biases, excitatory scale, and
inhibitory Vmem offset. The `SYNFIRE_1D_3_*` constants describe the exact
three-neuron reference configuration: neuron count, pulse timing and height,
and the fixed 3 by 6 synapse coefficient matrix. Matrix rows are receiving
neurons. Column `2*n` carries source neuron `n`'s excitatory pulse and column
`2*n+1` its inhibitory pulse. A zero coefficient disables that connection.

The three active connections are source 2 to target 0, source 0 to target 1,
and source 1 to target 2. Their Q8.24 coefficient is 14728164. Triangle states
start at 9454846 in Q16.16, while the C saturation comparison uses 9454845.
Keep both values separate to reproduce the reference model exactly. These
constants describe only the three-neuron 1D synfire example; other C network
examples may use different thresholds, weights, and stimulus schedules.

To check that the generated package has not become stale, run:

```powershell
python scripts/generate_neuron_params.py --check
```

Keep the floating-point source values in the Python script for traceability.
Use only the generated integer constants in synthesizable RTL.
